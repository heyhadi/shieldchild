Install on your child's phone in 2 minutes.

ShieldChild is standalone open-source software distributed directly as an APK. Follow these 4 easy setup steps:

  1. 1. Download the release APK

    Download app-release.apk from the official GitHub Releases page and tap to install on your child's Android phone.

  2. 2. Grant Core System Permissions

    Follow the guided 3-step wizard to grant Usage Access (to track screen time), Accessibility (anti-bypass watcher), and Display over other apps (lock overlay).

  3. 3. Activate Device Administrator

    In the Security tab, activate Device Administrator. This locks the Android OS "Uninstall" button and stops any attempt by the child to clear app data or force stop.

  4. 4. Save Offline Recovery Key

    Set your 4-to-8 digit Parent Master PIN and record your 16-character Master Recovery Key somewhere safe. You're fully protected!

Defense-in-depth architecture.

Why conventional parental control apps fail — and how ShieldChild solves it.

1. Sub-10ms Accessibility Interceptor

Kids frequently exploit lag in lock screens by repeatedly tapping Home or Settings. ShieldChild's Accessibility Service listens directly to OS window transitions. If a restricted app or Android Settings is entered during curfew, the service triggers GLOBAL_ACTION_HOME and re-snaps CurfewLockActivity to the front within milliseconds.

2. OS-Level Device Administrator Protection

Children can easily drag apps to the "Uninstall" trash icon or navigate to Settings → Apps → Uninstall. Registering ShieldChild as an active Device Administrator instructs the Android package manager to disable and grey out the Uninstall button permanently until parent authorization.

3. Reboot-Proof BootReceiver Watchdog

When an Android phone restarts, background apps are delayed by the OS. ShieldChild registers high-priority RECEIVE_BOOT_COMPLETED and persistent Foreground Watchdog services that calculate curfew rules before the launcher finishes loading, immediately locking the phone if bedtime curfew or daily limits are active.

4. Salted Cryptographic Authentication

Parent master PINs are protected with randomized cryptographic salts and SHA-256 digests. Failed PIN attempts incur escalating progressive time lockouts, while the offline recovery key allows instantaneous parent recovery without network connectivity.

Frequently Asked Questions

Can my child uninstall ShieldChild while they still have screen time?

No. ShieldChild uses Android's Device Administrator API. The Android operating system disables the "Uninstall" button in Settings and package installers. Even during daytime usage when free screen time remains, any attempt to access the Device Admin deactivation screen is automatically deflected back to the home screen.

How can a parent uninstall ShieldChild when needed?

Parents can uninstall cleanly at any time directly through the app. Open ShieldChild, authenticate with your Master PIN or fingerprint, go to the Security tab, and select Uninstall ShieldChild. The app will temporarily release the Device Administrator lock for 60 seconds, allowing you to remove it normally.

What if my child force-restarts the phone to bypass the lock?

Restarting the device does not bypass ShieldChild. The app evaluates curfew and daily limits immediately upon device boot via BootReceiver and a high-priority FullScreenIntent notification watchdog. If curfew is in effect, the lock screen is instantly enforced before any apps can be opened.

What if I forget my Parent Master PIN?

ShieldChild provides a 16-character Master Recovery Key (e.g. SHLD-9A4F-K82X-7M1P) generated during setup. On the lock screen, tap Forgot PIN? Use Recovery Key, enter your recovery key, and choose a new PIN. The device resets and unlocks immediately, completely offline.

Does ShieldChild track my family's data or require an account?

Never. ShieldChild requires no account, uses no cloud servers, and has zero network tracking. All screen time calculations and app policies exist solely inside the device's encrypted storage.

Which Android devices and versions are supported?

ShieldChild is engineered for Android 8.0 (Oreo, API 26) through Android 15+. It has been thoroughly verified on real hardware including OnePlus, Pixel, and Samsung devices running stock and custom Android ROMs (LineageOS).
